# Grundschule Höfingen – PWA

Mobile Informations-App für Eltern. Neuigkeiten werden automatisch über die öffentliche WordPress-REST-API der Schulhomepage geladen. Service-Kacheln verweisen auf die offizielle Schulhomepage. Kontaktperson: Alexander Burger (Name only).

## GitHub Pages
Unter Settings → Pages: Deploy from a branch, Branch main, Folder /(root), Save. Danach die angezeigte Pages-URL auf dem Smartphone öffnen und zum Home-Bildschirm hinzufügen.

## Hinweis
Der automatische Nachrichtenabruf setzt voraus, dass die Website öffentliche REST-API- und Cross-Origin-GET-Anfragen zulässt. Falls nicht, bleibt der Link zur Schulhomepage verfügbar.
